How to Generate a GitHub Personal Access Token

1Open GitHub Settings
Go to github.com and click your profile picture in the top-right corner. From the dropdown menu, click Settings.
2Go to Developer Settings
In the left sidebar, scroll all the way down to the bottom and click Developer settings.
3Select Tokens (classic)
Expand Personal access tokens and click Tokens (classic). This dashboard uses classic tokens for GitHub API access.
4Generate New Token (classic)
Click the Generate new token dropdown and select Generate new token (classic).
5Configure the Token
Fill in the token details:
  • Note — Give it a descriptive name (e.g. "vector-dashboard")
  • Expiration — Choose an expiration period (30 days recommended)
  • Scopes — Check the repo checkbox (full control of private repositories)
Minimum required scope: The repo scope is needed so the dashboard can read package.json files from private repositories in your org.
6Enable read:org Scope
Scroll down to the admin:org section and check the read:org checkbox.
Why this is needed: The read:org scope allows the dashboard to read org-level custom properties (Product, Repo-Class) used for filtering scan results.
7Generate & Copy the Token
Scroll to the bottom and click the green Generate token button.
Important: Copy your token immediately after it's generated — GitHub will only show it once! Paste it into the GitHub Personal Access Token field on this dashboard.
